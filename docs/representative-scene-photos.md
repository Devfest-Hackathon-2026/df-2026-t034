# 景点代表性实景照片：题材优先于随机

此前仅依据“文件属于景点条目/分类”筛选，随机选择会抽到明治神宫马匹活动特写、道顿堀历史版画。这些图片与地点相关，但不适合作为当前旅游建议的主图。此前只检查“有图”的验证不足，本次加入题材回归测试并实际查看替换照片。

## 通用规则

- 同时检查文件名、图片说明、分类和作品名；过滤画作、版画、插画、肖像、旧明信片、骑射/马匹/婚礼等活动、御守/绘马/酒桶等特写、地图及图解。低分图片不会仅因为文件名包含景点名称而随机胜出。
- 对建筑、入口、鸟居、参道、街道、路口、运河、全景等题材加分，按文件说明/EXIF拍摄日期或可识别文件名日期偏好较近年份。没有日期不宣称近期；上传时间不用于新旧排名。2000年前及未来年份不作当前旅行主图，历史文件名不会被较新的元数据时间覆盖。
- 只在最高分附近6分以内的候选间随机。如果最合适的图只有一张，保留它而不是为了避免重复换成较差或不相关图片。当前所有照片仍受来源/许可/尺寸/图片类型检查。
- 涩谷别称“渋谷スクランブル交差点(涩谷十字路口)”统一到“渋谷駅前交差点”；显示给用户的原景点名不变。
