## 真实调用与 iPhone

本次真实调用使用 `gemini-3.1-flash-lite`。服务端读取本机 `.env.local` 密钥；项目为用户确认的免费层级，未开通计费或公开部署。示例模型的可用性及免费额度仍以各自项目为准。

- 通过实际 Next.js `/api/chat` 连续发送「东京三天」→「两人、经济型、动漫和美食」→「改成两天」：三次均 HTTP 200，回复保留并修改旅行条件。
- 用户在自己的 iPhone Expo Go 中确认同样三轮均有真实回复，并记住先前条件；之后继续到第四轮。
- 用户确认键盘不会挡住输入框或发送按钮，等待回复时不能重复发送。
- 手机与 Mac 在同一普通 Wi-Fi 后连通；先前 iPhone 热点的 `192.0.0.2` 地址未能让手机连回电脑。更换网络后应重新配置电脑局域网地址并重启/Reload Expo。
- 手机端错误分类和请求重试有自动化覆盖；未逐项在 iPhone 人为触发全部错误类型。

该模型支持 Thinking；当前实现未显式设置高强度思考或展示思考摘要。系统指令固定日本旅行助手的行为，实际回答由 Gemini 根据每次传入的完整对话生成，没有预置旅行回复。

## 当前边界

只提供本地开发的文字聊天；没有登录业务、支付、行程保存或实时搜索。对话当前保存在手机页面内存中，完整 Reload 或退出后可能丢失。Google 模型可能返回繁忙、限流或不可用错误，界面会显示错误并允许主动重试，不能保证上游始终可用。

启动与配置步骤见 [iPhone 聊天联调指南](iphone-chat-setup.md)。根地址返回服务状态 JSON，手机界面仅通过 Expo Go 打开。
